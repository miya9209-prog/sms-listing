# 광고발송 고객리스트 생성

업로드한 xlsx 파일에서 아래 조건으로 고객을 추려 다시 xlsx로 다운로드하는 Streamlit 앱입니다.

## 지원 조건
- 실결제금액 이상
- 실결제율 이상
- 주문당단가 이상
- 최종주문일 지정일까지
- 최종접속일 지정일까지

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 기준 컬럼
- 실결제금액
- 실결제율
- 1회주문당금액
- 최종주문일
- 최종접속일

업로드 파일에서 `원본` 시트를 우선 읽고, 없으면 첫 번째 시트를 읽습니다.
