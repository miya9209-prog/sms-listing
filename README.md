# 광고발송 고객리스트 생성

업로드한 고객 엑셀 파일에서 조건별로 고객을 추출하고, 정렬 후 xlsx 파일로 다운로드하는 Streamlit 앱입니다.

## 주요 기능
- xlsx 파일 업로드
- 실주문금액 범위 필터
- 실결제율 범위 필터
- 주문당단가 범위 필터
- 주문일 기간 필터
- 접속일 기간 필터
- 문자수신동의 고객만 필터
- 불량회원 제외
- 정렬 항목 선택
- 결과를 xlsx로 다운로드
- 추출 결과를 이름 붙여 DB처럼 저장/불러오기/재다운로드/삭제

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 참고
- `주문당단가`는 업로드 파일의 `1회주문당금액` 컬럼을 기준으로 처리합니다.
- 날짜 비교는 시간 제외 후 날짜 기준으로 처리합니다.
- 저장 리스트는 `data/saved_lists.db`와 `data/saved_lists/` 폴더에 보관됩니다.
