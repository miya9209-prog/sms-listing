# 광고발송 고객리스트 생성

업로드한 xlsx 파일을 조건별로 필터링하고, 결과를 다시 xlsx로 저장/다운로드하는 Streamlit 앱입니다.

## 주요 기능
- 실주문금액 시작~끝 한 줄 입력
- 실결제율 시작~끝 한 줄 입력
- 주문당단가 시작~끝 한 줄 입력
- 주문일 시작~끝 한 줄 입력
- 접속일 시작~끝 한 줄 입력
- 문자수신동의 고객만 필터
- 불량회원 제외
- 정렬 기준 선택
- 결과 xlsx 다운로드
- 저장 리스트 DB 보관 / 불러오기 / 삭제

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
